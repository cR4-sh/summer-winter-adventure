# Summer Winter Adventure · Tech

Техническая ветка сборки для Minecraft Java 1.21.1, NeoForge 21.1.267 и Java 21. NTM: Decentralized Edition ведёт промышленную прогрессию, Unbound даёт цели для космических экспедиций. AE2 нужен для хранения и автокрафта, CC: Tweaked — для мониторинга и управления. JEI показывает рецепты, Jade — состояние машин, FTB Quests связывает этапы с объяснениями. Create в сборку не входит.

## Установка

1. Создай отдельный профиль с Minecraft 1.21.1 и NeoForge 21.1.267. Для выделенного сервера используй [официальный установщик NeoForge](https://maven.neoforged.net/releases/net/neoforged/neoforge/21.1.267/neoforge-21.1.267-installer.jar) с аргументом `--installServer`.
2. Из корня ветки запусти с Python 3.11 или новее:

   ```sh
   python3 install.py /путь/к/игровой-папке
   ```

   Укажи каталог профиля, в котором лаунчер хранит `mods` и `config`, или корень установленного сервера. Установщик скачает 15 JAR с площадок авторов, проверит SHA-256 из `mods.lock.json` и скопирует настройки, квесты и скрипты из `overrides`. Повторный запуск использует уже скачанные JAR с корректным хешем и обновляет файлы сборки. Для сетевой игры выполни установку на клиенте и сервере.
3. Запусти профиль с Java 21 и создай новый мир. В FTB Quests открой главу **«Космическая программа»**. Для наблюдений, сборки и запуска пользуйся Звёздным журналом Unbound.

## Прогрессия

| Рубеж | Производство NTM | Что открывает в Unbound |
| --- | --- | --- |
| Первый запуск | Титановые пластины, бакелит, интегральная схема и 1 000 мБ керосина в сборочной машине | Герметичный узел нужен для лунной кабины. Астрономия остаётся доступна со старта. |
| Другие маршруты | Оптическое стекло Unbound, титановая пластина и бакелит | Усиленные иллюминаторы для шаттла Края и водолазного колокола. |
| Верфь | Штатная авионика Unbound, усиленная электроникой, мотором и быстрорежущей сталью NTM | Один блок управления для трёх вариантов консоли. Каждый по-прежнему требует собственный трофей. |
| Дальняя ракета | Навигационный кристалл Unbound, свинцовые пластины и продвинутая схема | Экранированное ядро для дальней ракеты. Штатная цепочка кабин и трофеев остаётся целой. |
| Межзвёздный полёт | Квантовая схема, деш, быстрорежущая сталь и Пороговый ключ Unbound | Контроллер для первой ступени межзвёздного двигателя. Следующие ступени используют предыдущую. |

Сборочная машина NTM также наполняет пустую канистру Unbound за 1 000 мБ керосина. Это даёт земной фабрике полезный расходный материал для повторных экспедиций. У игрока остаются штатные источники топлива Unbound, включая местное производство вне Земли. Титан из ильменита Unbound уже совместим с прессом NTM по общему тегу слитков.

Производственные сценарии связаны через детали и топливо. Электросети NTM и Unbound работают по правилам своих модов. Древние врата сохраняют штатные условия. В данных Unbound пробуждение врат планет требует победы над местным боссом и дополнительных действий.

## Содержание и баланс

Unbound заявляет 26 исследуемых миров, 16 корпусов кораблей и 42 босса и стража. У NTM отдельные крупные цепочки металлургии, нефтехимии, электроники и реакторов. Ориентиры для одиночной игры от начала мира: **8–15 ч** до первой лунной экспедиции с возвращением, **25–50 ч** до нескольких планет и своего корабля, **60–110 ч** до межзвёздного полёта и развитого завода, **120–200+ ч** для большинства боссов, маршрутов и поздней промышленности. Это оценки для знакомого с техносборками игрока, без замера прохождения.

NTM даёт револьверы и пистолеты, пистолеты-пулемёты, дробовики, винтовки, пулемёты, Tau Cannon и Tesla Cannon. Защита варьируется от Hazmat и HEV до силовых комплектов T45, T-51b и Remnants. У Unbound есть планетарное оружие и комплекты, например Crater Hammer и Crater Carapace с Луны, Prism Blade и Faceted из Грани, а позднее String Bow и Meteoric Plate. Скафандр Unbound — отдельный слой под боевой бронёй, с кислородом и модулями защиты от среды. По разнообразию обоих модов достаточно для первой версии. Сравнение эффективности оружия в фазовых боях с боссами требует игры на этих версиях.

## Проверка

Установщик проверен установкой с нуля и повторным запуском. На выделенном NeoForge-сервере загружаются вся сборка, пять заданий, шесть добавленных и восемь изменённых рецептов. Клиентский запуск, интерфейс Star Journal, фактический цикл машины и экспедиции от старта до возвращения требуют отдельной проверки в выживании. В серверном логе есть предупреждения исходного NTM о пропущенных рецептах серы и киновари. Они находятся вне изменений этой ветки.
