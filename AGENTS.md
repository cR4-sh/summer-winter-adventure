# Согласование косметики

Перед выкладкой косметических изменений на прод покажи владельцу сборки результат в игре и дождись явного согласования. Для моделей, брони, оружия и вида от первого лица приложи скриншоты. Для анимаций приложи видео. Звуки боевых действий показывай в видео со звуком.

Используй отдельный тестовый профиль для разработки и записи превью.
